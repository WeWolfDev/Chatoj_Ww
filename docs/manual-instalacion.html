2. Descarga e instalación

  1. Descarga o clona el repositorio público: github.com/WeWolfDev/Chatoj_Ww.
  2. Instala Godot Engine 4.7.2 Standard desde el sitio oficial de Godot. En Windows, descomprime el paquete; en macOS o Linux, sigue las instrucciones de instalación de esa plataforma.
  3. Abre Godot y, en el gestor de proyectos, pulsa Importar (o Import).
  4. Selecciona el archivo Project/CHATOJ/CHATOJ/project.godot dentro de la carpeta descargada y confirma la importación.
  5. Abre el proyecto y espera a que finalice la importación inicial de recursos. La carpeta .godot/ se genera automáticamente y no debe compartirse como parte de la entrega.

El archivo que se importa es project.godot; no importes la carpeta del repositorio completa como si fuera un proyecto Godot.

3. Ejecución y navegación

Desde el editor

  1. Abre el proyecto importado en Godot.
  2. Pulsa F5 o el botón Ejecutar proyecto. El juego abre el menú principal.
  3. Selecciona Jugar para iniciar el mapa principal.
  4. Para cerrar el juego, selecciona Salir en el menú, o cierra la ventana.

Desde una terminal

Desde la raíz del repositorio, con el ejecutable de Godot disponible en el PATH:

godot --path Project/CHATOJ/CHATOJ

En macOS/Linux se puede indicar la ruta absoluta del ejecutable de Godot si no está en el PATH. En Windows, reemplaza godot por el nombre o ruta del ejecutable instalado, por ejemplo Godot_v4.7.2-stable_win64.exe.

4. Compilación, exportación y pruebas

Ejecución de pruebas de regresión

Importa primero el proyecto para que Godot genere su caché. Desde la raíz del repositorio, ejecuta:

godot --headless --path Project/CHATOJ/CHATOJ \
  --script res://tests/regression.gd

En Windows, sustituye la primera palabra por la ruta al ejecutable. El informe Project/CHATOJ/CHATOJ/docs/VERIFICACION.md registra 75 comprobaciones aprobadas y 0 fallos en la ejecución documentada; no cubre una partida completa ni pruebas de balance de todos los jefes.

Exportar un ejecutable

El repositorio no incluye un ejecutable ni un perfil de exportación verificado. Para generar una compilación:

  1. En Godot, abre Proyecto > Exportar.
  2. Añade el preset de la plataforma destino y, si Godot lo solicita, instala las plantillas de exportación de la misma versión.
  3. Configura el nombre y la ruta del archivo de salida y pulsa Exportar proyecto.

También se puede usar la terminal después de crear un preset llamado Windows Desktop y de instalar las plantillas correspondientes:

godot --headless --path Project/CHATOJ/CHATOJ \
  --export-release "Windows Desktop" \
  build/CHATOJ.exe

El nombre del preset debe coincidir exactamente con el definido en el perfil de exportación. Este comando es una plantilla de uso; no se ha generado ni validado una compilación con él en esta entrega.

5. Solución de errores comunes

ProblemaSolución
Godot no encuentra el proyecto.Importa el archivo Project/CHATOJ/CHATOJ/project.godot, no el directorio raíz del repositorio.
La primera ejecución tarda o muestra recursos cargando.Espera a que termine la importación automática. No borres archivos dentro de assets/.
F5 no inicia el juego.Confirma que se abrió el proyecto correcto y que la escena principal es res://scenes/ui/main_menu.tscn. Prueba Ejecutar proyecto desde el editor.
El comando godot no existe.Agrega Godot al PATH o ejecuta el binario con su ruta completa. En Windows usa el ejecutable .exe.
Falla la exportación.Verifica que el preset de exportación coincida con el nombre indicado en el comando y que estén instaladas las plantillas para Godot 4.7.2 y la plataforma elegida.
El control no responde.Haz clic en la ventana del juego para darle foco y confirma que se está usando el teclado configurado (WASD) y los botones correctos del mouse.
